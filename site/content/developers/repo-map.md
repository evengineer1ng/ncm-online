# Repository Map

The repository is a workspace, not one package. It holds the live server's source, native plugins, the original
single-player mod, tooling, research and the design record. This map covers every top-level area. **Bold** marks
what you most likely want.

Legend: **S** server · **C** client · **Sh** shared · **N** native plugin · **T** tooling · **D** docs/data.
Status uses this site's [labels](../status.md).

## `ncm/online/resources/`: the OPEN//77 resources (the server) {{status:live}}

Each directory is one OPEN//77 resource: `open77.lua` (manifest), `server/`, `client/`, `shared/` (incl. the vendored
`shared/core/`), sometimes `web/`.

| Path | Kind | Notes |
|---|---|---|
| **`ncm_league/`** | S | Entry: `server/main.lua`. **Owns the database schema:** `server/schema/NNN_*.lua` (+ a `server_script` line per migration in `open77.lua`). Calendar, race, guide, economy, market, trade, records, graph, collapse. |
| **`ncm_world/`** | S, C | Identity, presence, garage, fuel, vehicle condition, engineering, Race Week (`server/week.lua`), scars, Deep. Client: F6 panel (`client/panel.lua`, `web/panel.html`), HUD, race and venue screens, nav input. |
| **`ncm_paddock/`** | S (+C) | The NPC league. Entry `server/main.lua`; `world`, `races`, `garages`, `days`, `billie`, `markets`, `exchange`, `story`, `week`. Client: Talk prompts, live races. Host-stub test: `tools/test-paddock-host.lua`. |
| `ncm_engineering/`, `ncm_workshop/`, `ncm_build/` | C / S | F9 panel, Workshop bench, Build primitive. |
| `ncm_broadcast/`, `ncm_radio/`, `ncm_observer/`, `ncm_scanner/` | S, C | Presentation and spectating. |
| `ncm_speed/`, `ncm_slipstream/`, `ncm_audio/`, `ncm_sky/` | S / C | Speed limits, aero wake, sound, universe drawing. |
| `ncm_universe/`, `ncm_space/`, `ncm_aero/` | S | {{status:experimental}} Astronomical substrate (read-only shadow mode), Snowglobe racing, aerospace racing. |
| `ncm_race_week_map/`, `ncm_world_layer/`, `ncm_build_kit/`, `ncm_earth_underlay/` | D | Generated by NCWE Studio. Do not hand-edit. |
| `ncm_link/`, `ncm_probe/`, `ncm_weather_probe/` | S | {{status:dev}} Dev-only or throwaway probes; withheld from Online. |

## Where configuration lives

- **Server tunables:** each resource declares its tunables once (`Open77.tunables.declare`), and the server overrides
  them from its own `tunables.json`. Kill switches follow the `<name>Enabled` pattern.
- **Server config:** OPEN//77's `server.jsonc` is never committed (it holds the server licence). Credentials come from
  environment variables, which `tools/o77-server.ps1` injects from the Windows DPAPI store (`tools/ncm-secret.ps1`).
- **Native plugin config:** a JSON file next to each DLL (e.g. `ncm/rig_bridge/ncm_rig_bridge.json`).
