# The NCM Family

**Night City Motorsports (NCM)** is a racing and motorsports project for Cyberpunk 2077. It exists in more than one
form, and they are not the same product.

| | What it is | Status |
|---|---|---|
| **NCM single-player releases** | The original NCM mod for single-player Cyberpunk 2077, published on Nexus Mods: a CET-based racing and career framework. | Released; its payload is preserved in this repository under `ncm-localized/` {{status:historical}} |
| **NCM Online** | The multiplayer branch on OPEN//77: this server and this repository. Where NCM is actively developed. | {{status:live}} alpha |
| **NCM 3.0** | A planned single-player release that brings what NCM Online has become back to single player, through a native host that runs NCM's server resources inside the game. | {{status:in-development}}, currently on hold |

**NCM Online is not NCM 3.0.** NCM Online's systems are the source material for NCM 3.0, and work on Online
informs it, but they are separate products with separate releases. Nothing here means a single-player version of a
feature already exists.
