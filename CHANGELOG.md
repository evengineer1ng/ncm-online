# Changelog

The full, maintained changelog is on the website:
**[evengineer1ng.github.io/ncm-online/changelog.html](https://evengineer1ng.github.io/ncm-online/changelog.html)**.

It is built from two sources, so nothing is written twice:

- **Player release notes** live in `ncm/online/resources/ncm_world/client/landing_content.lua` (`releases`). The game
  shows them on its landing panel, and the website generates its release list from the same file.
- **Project milestones** live in `site/content/changelog.md`, newest first, one line each.

Every decision behind a change is in `docs/ncm-online/DECISION_RECORD.md`.
