## Scope

### 1. MariaDB (local)
- Install MariaDB Server via winget; root password generated by script and stored DPAPI-encrypted (`db-root`), never printed.
- Create database `ncm` (utf8mb4) and user `ncm@127.0.0.1` with the grants from the platform database guide (SELECT/INSERT/UPDATE/DELETE/CREATE/ALTER/INDEX on `ncm.*`).
- Connection string `Server=127.0.0.1;Port=3306;Database=ncm;User ID=ncm;Password=…;` stored as secret `db-connection`; `tools/o77-server.ps1` injects it as `OP77_DATABASE_CONNECTION`; `database.enabled = true` in `server.jsonc` (masked patch).

### 2. `ncm_league` skeleton + migration runner
- New resource (server only for now) with `database.access`.
- `server/migrations.lua`: `schema_migrations(version, name, applied_at)`; applies `server/schema/*.lua` in order inside `MySQL.ready`; idempotent (second run no-op); commands `ncm.db.status`, `ncm.db.migrate`.
- `001_identity.lua`: `ncm_driver`, `ncm_driver_binding`, `driver_profile`, `content_pack` — exactly the tables M2 needs.

### 3. E0 part B probes — `ncm_probe` (throwaway, no permissions)
- Event bus: `ncm_probe` fires `TriggerEvent("ncm:probe:ping")`; `ncm_world` logs receipt → host-wide vs VM-local decided.
- Permission gating: `Open77.vehicles.all()` from a resource without `world.vehicles` → record the refusal shape.
- Tunables: declare → set → pending → promote round-trip, logged.
- Readiness: `Open77.ready.participate` + hold/release on `onPlayerConnected` with a 2 s delay; measure that `onPlayerReady` waits.
- Restart cleanup: `Open77.state.save/load` across `restart ncm_probe`; the probe's `RegisterCommand` disappears while stopped.

Protocol is undocumented ("protocol=1, one-line OK/ERR reply"); attempt text line framing, fall back to printing the console instruction.
