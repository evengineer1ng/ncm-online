## What it does
- **Core:** `course.gates` (start line, authored intermediates, finish line; SP finish-line geometry: sign flip along the direction of travel, half-width, arm distance), `session.grid` (check-in order, two columns behind the line), `session.race` (pure state machine forming → gridded → countdown → running → finishing → complete; grid presence, jump-start penalty, ordered/positioned gate reports, DNS/DNF, finish window, classification, public view). 12 tests, both interpreters.
- **ncm_league (server):** `server/race.lua` forms a session from the checked-in entries when entries close (T−60), reads the server's own positions for the grid check (T−30 → absent = DNS), runs five lights (T−5..T−0) as replaced toasts, validates `ncm:gate` reports against the server's position for that player (45 m), classifies, persists `session` / `session_result` / `ledger` (0 eddies) via migration 004, updates `entry.state`, publishes `GlobalState.ncmSession`, writes `ncmResult` to entrants' bags and clears `ncmEntry`. Disconnect → DNS/DNF. `/ncm.race` prints live sessions.
- **ncm_world (client):** `client/race.lua` — grid slot marker + card, lights via server toasts, next-gate marker + racing card, local crossing detection (core geometry) reported to the server with a 2 s retry while still near the gate, result card; the heartbeat card yields while a session is active.

## v0 scope notes
- Street sprints are **open-route** like SP point-to-point: start line and finish line only. Authored intermediate gates are supported by the code and tests but no polyline data exists for the SP roots (E1 not run), so none are placed live. Criterion 4's "gate 3 before gate 2" is proven in the core tests; live proof needs an authored course (M3.x with E1).
- Grid slots are geometric (two columns behind the start node along its heading). If a start node's heading points across the road, slots will look wrong — the fix is per-node heading data, not code.
- Timing uses the server clock at report receipt (fractional unix seconds); the client's clock is never trusted.
