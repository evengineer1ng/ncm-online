## Discrepancies / lessons
1. `--setup-listen <url>` as a CLI flag was re-parsed as one token when the server relaunched itself after setup → post-setup boot died. Use `OP77_WARDEN_SETUP_LISTEN` instead. (Platform note.)
2. `OP77_CONNECT`/`OP77_CONNECT_MASTER` in a directly-launched game's environment do **not** produce an auto-connect: the plugin dispatches a boot connect target only through the launcher handoff. `OP77_IDENTITY_PROFILE` and `OP77_PLAYER_NAME` **are** honoured (`identity-ncm-tester2-v1.dat` created). The shell's documented substitute works: dev console (`` ` `` key) → `resource.emit open77:shell:autoconnect <endpoint> alpha`.
3. Without `SteamAppId`/`SteamGameId` in the environment the direct exe may be relaunched by Steam (env lost); the launcher script sets them and verifies the pid survives 25 s.
4. Warden dashboard polling floods the console at ASP.NET `info` level while the panel is open.
5. An 8-second `--help` probe started onboarding on all interfaces and wrote a throwaway Warden identity; deleted before real onboarding.
6. **Launcher quarantined 223 local (Solo-profile) files** when browsing servers — CET mods incl. MT_Ecosystem, CustomMapMarkers `.reds`, RB15/livery tweaks — into a recoverable quarantine; "Play your own game" restores them. Confirms the two-profile model; SP NCM is unavailable while the OPEN//77 profile is active.
7. `Open77.players.position` freshness **verified**: after player 1 walked ~13 m the read moved from (379.5, −2408.5, 182.1) to (369.9, −2417.1, 181.9) while stationary player 2 stayed at (381.3, −2401.7); earlier identical values were a stationary player. Sample age/cadence under vehicle speeds remains an E2/E8 measurement.
8. The in-game slash command path: chat `T` → `/ncm.where`; server-side `RegisterCommand` reached via `Player 1 executed 'ncm.where' via ncm_world`.

## M0.2 closure notes
- Debug bridge: `ping` → `OK pong protocol=1` **only from an elevated shell**; a normal process can open the pipe read-only (write denied, error 5). A scripted second-client autoconnect therefore needs admin; deferred until needed (the in-game console route is the procedure).
- Devkit MCP for .82: npm `@open2077/mcp` latest 0.1.2; devkit repo index snapshot is still **2.31.13+op77.78** (commit 2026-09-19T08:05Z). No .82 card set exists publicly yet; .78 cards remain the lower bound.
- Lesson applied: resource scripts are subject to the same Lua-5.4 pitfalls as core (`%d` with floats). `ncm_probe` set to `auto_start false` (on-demand via `start ncm_probe`).
- Character creator appears once per identity now that the DB is on (`open77_appearance` persistence); subsequent joins restore it (`revision=1 snapshot=yes`).
