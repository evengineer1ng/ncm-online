## Why this is first

Every later package needs three things that do not exist yet: a place for engine-free core code with a test runner that enforces the CET/OPEN//77 Lua intersection, a local OPEN//77 stack on this PC with two identities, and proof that a vendored-core resource loads on that stack. M0.1 builds exactly those and nothing else. It does not touch `ncm-localized/` or the game folder's mod set.

## Scope of M0.1

### 1. Repository scaffold (`ncm/`)
- `ncm/core/init.lua` — the `Core` registry: `Core.define(name, factory)` / `Core.get(name)`; no `require`, no globals beyond `Core` when loaded by a host.
- `ncm/core/vocabulary/ids.lua` — UUID v4 from an injected RNG, id formatting/validation for the id kinds in architecture §2.2.
- `ncm/core/vocabulary/provenance.lua` — enums and validators for provenance, context, topology, backend, event class, session kind, entry state.
- `ncm/core/COMPAT.md` — the Lua intersection rules core must obey (CET = LuaJIT 5.1-class; OPEN//77 = Lua 5.4.8): no `//`, no bitwise operators, no reliance on the 5.4 integer subtype (`%d` with non-integral values), `unpack`/`table.unpack` via shim, no `goto`, no `os`/`io`/`require`/`package`, no `string.pack`, `#` only on sequences.
- `ncm/online/resources/ncm_world/` — `open77.lua`, `server/main.lua`, `client/main.lua`, `shared/core/**` (generated).
- `ncm/online/profile/server.dev.jsonc` — dev fragment: `resources.root` → `ncm/online/resources`, `maximumPlayers` 8, `requiredMods.enabled=false` for M0.1, loopback download URL.
- `tools/ncm-build.ps1` — vendors `ncm/core/**` into each resource's `shared/core/` and rewrites the manifest's ordered `shared_script` block between markers.

### 2. Test runner
- `tools/ncm-test.ps1` — runs `ncm/core/tests/*.lua` under **Lua 5.4** and under **LuaJIT**; non-zero exit on any failure; prints both interpreters' versions.
- Installed 2026-09-19: Lua 5.4.6 (`%LOCALAPPDATA%\Programs\Lua\bin\lua.exe`, winget DEVCOM.Lua) and LuaJIT 2.1 (`%LOCALAPPDATA%\Programs\LuaJIT\bin\luajit.exe`, winget DEVCOM.LuaJIT). Verified: LuaJIT rejects `//` and bitwise ops; 5.4 rejects `%d` with non-integral floats — running under both is a genuine intersection check. The static compat lint becomes optional hardening.
- Two seed tests: ids (uuid shape, determinism under a seeded RNG) and provenance validators.

### 3. Local OPEN//77 stack
- Unpack `open77-server-2.31.13+op77.82-win-x64.zip` (found in Downloads, 2026-09-18) to `tools/open77/server/` — outside the game folder and outside `ncm-localized/`. Record its actual build; note that the hosted MCP index tops out at **.78** ("no index published for .82"), so API cards are a lower bound until the index catches up.
- Launcher (`Open77Launcher.exe`) installed; preview account enrolled.
- Agent-testing toolkit not in the package. **Second client procedure (verified):** `tools/o77-client.ps1 -Profile <name> -Name <displayName>` starts the game with `OP77_IDENTITY_PROFILE`/`OP77_PLAYER_NAME` (+ `SteamAppId` so Steam does not relaunch it); at the main menu open the dev console (`` ` ``) and run `resource.emit open77:shell:autoconnect 127.0.0.1:11778 alpha`. A fresh identity enrols on alpha without a sign-in.
- `tools/o77-backup-saves.ps1` — backs up the shared save folder before any multi-client session (agent-testing guide warning).

### 4. `ncm_world` v0
- Manifest: `resource "ncm_world"`, `version "0.0.1"`, `shared_script` block (vendored core), `server_script "server/main.lua"`, `client_script "client/main.lua"`, no permissions beyond what `ncm.where` needs.

- Client: on start print resource generation and `Open77.runtime.luaVersion`.
- No DB, no identity minting, no world logic — those are M0.2 and M2.

## Completion criteria (all must hold)

1. `tools/ncm-test.ps1` exits 0 with the two seed tests passing under Lua 5.4 **and** under LuaJIT or the compat lint, and exits non-zero when a deliberate COMPAT violation is introduced (proved once, then reverted).
2. `tools/ncm-build.ps1` regenerates `ncm_world/shared/core/**` and the manifest block idempotently (second run produces no diff).
3. The dedicated server starts from `tools/open77/server/` with the dev profile, loads `ncm_world`, and logs its Lua version and the core `ids` module version.
4. Two game clients from this PC, under two distinct identities, are in-world on the local server at the same time; each sees the other's nameplate; `ncm.where` answers for both with distinct `userId`s.
5. A Lua edit to `ncm_world` hot-reloads without a server restart and the client reports a new resource generation.
6. `tools/o77-backup-saves.ps1` produced a dated backup before criterion 4 was exercised.
7. `docs/ncm-online/experiments/E0_<date>.md` part A is written with the build pins above and the MCP-index lag noted.
8. `git`-free discipline: nothing under `ncm-localized/`, `install-records/`, or the game folder changed (hash spot-check of `ncm-localized` payload against `evidence/ncm-source-inventory.json` plus the checkpoint-06 hashes).
