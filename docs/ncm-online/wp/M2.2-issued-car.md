# WP M2.2 — Get issued a car

Milestone: M2 (world layer). Status: **COMPLETE 2026-09-19** (driving check by owner). Depends on M2.1.

## What it does
`/ncm garage` lists NCM's street classes (Muscle, Sport, Tech, Nomad, Bike — the SP vehicle pool, now core data `data.vehicle_pool`); `/ncm car <Class>` asks core `world.provisioning.issue` for a pool record (model `issued`, cost 0 per L21), spawns the `_player` variant as a canonical server vehicle 5 m ahead / 3 m right of the driver facing their heading, logs the issue in `issued_vehicle` (migration 002), and returns any previous car first. `/ncm return`, disconnect and resource stop all return the car (vehicle removed, row closed with a reason).
