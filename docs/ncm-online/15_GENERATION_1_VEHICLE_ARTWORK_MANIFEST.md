# NCM Generation 1 Vehicle Collection --- Artwork Source Manifest

> Working asset manifest for the 27 conceptual vehicles in NCM
> Generation 1. This is a sourcing document, not a change to the
> canonical vehicle catalogue. \## Source strategy - **Primary grid
> art:** Cyberpunk Wiki's extracted **Vehicle Icons**. The archive
> describes these as vehicle icons taken from *Cyberpunk 2077*. -
> **Primary detail art:** Cyberpunk Wiki's **Vehicles Database** images
> where an appropriate image exists. - **Formula exception:** Red Bull
> Racing RB15 uses a Wikimedia Commons source because it is not a stock
> Cyberpunk vehicle. - **Locked/undiscovered art:** derive a
> silhouette/dark treatment from the same chosen discovered image. Do
> not source a second mystery image. - **Important:** NCM conceptual
> identities do not always equal one exact CDPR trim. Rows marked
> `confirm` or `TEMP` should be checked against the actual NCM
> TweakDB/record mapping before assets are shipped. \## Canonical

## Variant notes that need NCM-side confirmation

-   **Colby Pickup:** mapped to the CX410 Butte as the clean pickup
    representative.
-   **Colby:** mapped to C125 icon / C240t database art. Confirm the
    exact record NCM means by the conceptual `Thorton Colby` slot.
-   **Quadra Type-66:** mapped to 640 TS as the standard road
    representative. The Nomad slot separately maps to Javelina.
-   **Quadra Turbo-R:** mapped to V-Tech. Confirm whether NCM
    intentionally collapses 740 and V-Tech or points to one exact
    record.
-   **Brennan Apollo Sport:** the indexed icon archive contains an
    explicit Apollo 650-S icon; the wiki describes 650-S as the sporty
    factory version.
-   **Brennan Apollo Nomad:** the indexed archive exposes Scorpion's
    Apollo, while the game also has generic Nomad Apollo records.
    Confirm the actual NCM record before shipping the art.
-   **Yaiba Kusanagi Tyger Claw:** the wiki identifies the Tyger Claw
    variant as **Mizuchi**. No Mizuchi icon appeared in the indexed icon
    archive, so CT-3X is only a temporary visual placeholder in this
    manifest.
-   **Yaiba Kusanagi Animals:** the wiki identifies the Animals version
    as **Misfit**. No Misfit icon appeared in the indexed icon archive,
    so Akashita is only a temporary visual placeholder in this manifest.
    Do not ship that substitution without checking the game
    assets/record.
-   **RB15:** all ten NCM liveries still resolve to the single
    conceptual RB15 Collection identity. The collection image should
    therefore represent the chassis identity, not create ten catalogue
    slots.

## Suggested asset output convention

When the source choices are confirmed, normalize them into NCM-owned
filenames rather than coupling UI code to wiki filenames:

``` text
collection/<vehicleKey>/discovered.webp
collection/<vehicleKey>/locked.webp
collection/<vehicleKey>/detail.webp
```

A small manifest can then map `vehicleKey` to those local files. This
keeps external URLs out of runtime UI and lets NCM replace art later
without changing catalogue identity.

## Provenance / licensing caution

The Cyberpunk Wiki category pages state that community content is
available under **CC BY-SA unless otherwise noted**, but individual file
pages should still be checked before redistribution. The underlying
vehicle imagery also depicts CD PROJEKT RED game content. Wikimedia
Commons files carry per-file licenses shown on their description pages.
Preserve source URL, creator/uploader where applicable, and license
notes alongside any asset that NCM redistributes.
